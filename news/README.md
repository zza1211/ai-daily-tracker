# 新闻资讯归档

按日期记录模型与产品、产业与政策、研究公告和社区讨论。完整来源与采编规则见 [sources/feeds.md](../sources/feeds.md)。论文的技术解读归日报“相关论文”，项目版本细节归“相关开源项目”；同一成果只计一个主事件，跨栏目交叉引用。

## 单条格式

### 标题

- 日期与状态：原始发布时间；当日新增 / 近期补充 / 社区观点 / 待核验。
- 类型：产品公告 / 公司与产业 / 政策 / 研究公告 / 社区讨论。
- 来源：原始链接；媒体或论坛发现链接可另附，保留社区、作者与讨论日期。
- 事实摘要：发生什么、影响谁、技术或产品变化是什么。
- 证据边界：官方确认、作者自报、第三方测试或尚未核验；讨论观点明确署名。
- 跟踪：待核实的问题、原始材料、独立评测。

新闻默认 24 小时；72 小时补充独立标注。不要把旧成果的新转载当作新发布；不要复制论文栏填充新闻数量。检索失败与覆盖缺口须在日报披露。
