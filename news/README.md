# 新闻资讯归档

这里存放 AI 训练/推理、Agent、记忆方向的新闻与官方公告，按 `YYYY-MM-DD.md` 每天归档。首日先完成论文和开源项目基线，新闻从后续日报开始按天归档。

## 推荐来源

- 模型/实验室官方博客与公告（DeepSeek、Qwen、Google DeepMind、Meta AI、OpenAI、Anthropic 等）
- GitHub Releases、项目官方博客和维护者公告
- arXiv cs.AI、cs.LG、cs.CL 的最新提交
- 重要会议（NeurIPS、ICML、ICLR、ACL、EMNLP、MLSys、OSDI 等）官网

## 单条格式

```markdown
### 标题

- **日期**：YYYY-MM-DD
- **类型**：论文发布 / 项目发布 / 版本更新 / 公司公告 / 会议
- **来源**：[官方链接](https://...)
- **涉及方向**：训练 / 推理 / Agent / 记忆
- **摘要**：两三句话说明事实、技术变化和影响。
- **跟踪**：需要后续验证的代码、指标、许可证或复现实验。
```
