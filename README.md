# AI 每日进展追踪

这个项目用于持续跟踪 AI 领域的进展，重点关注 **训练与推理、Agent、记忆系统**，并将每天的新内容整理为 Markdown。

## 内容结构

- [`sources/papers.md`](sources/papers.md)：近两年热点论文基线（论文原文、代码、方向标签、简要点评）
- [`sources/projects.md`](sources/projects.md)：近两年值得跟踪的开源项目（官方仓库/文档、用途、方向标签）
- [`sources/feeds.md`](sources/feeds.md)：后续每日检索的论文、项目和新闻入口
- [`news/README.md`](news/README.md)：新闻资讯的来源、筛选规则和归档格式
- [`daily/`](daily/)：按日期生成的每日资讯；首日基线见 [`daily/2026-11-11.md`](daily/2026-11-11.md)
- [`templates/daily.md`](templates/daily.md)：每日 Markdown 模板
- [`scripts/new_daily.ps1`](scripts/new_daily.ps1)：生成指定日期的日报文件

## 覆盖范围

首版基线时间窗：**2024-11-11 至 2026-11-11（Asia/Shanghai）**。优先收录：

1. 训练：预训练、后训练、强化学习、数据与评测、开放模型训练系统；
2. 推理：测试时计算、推测解码、KV Cache、量化、服务引擎、长上下文；
3. Agent：工具调用、规划、浏览器/代码 Agent、多 Agent、Agent 评测；
4. 记忆：长期记忆、检索、知识图谱、遗忘、跨会话学习与记忆评测。

论文和项目优先保留原始链接（arXiv、会议页面、实验室公告、官方 GitHub/文档）。每条记录保留日期和标签，便于后续增量更新与去重。

## 日常更新约定

- 每天在 [`daily/`](daily/) 新建 `YYYY-MM-DD.md`；
- 只加入当天窗口内新发布、重要更新或值得复盘的内容；
- 论文、项目、新闻分别归档，日报只做摘要并链接回分类文件；
- 新条目应标记 `新增`，后续状态变化用 `更新`；
- 每周回看一次“待跟踪”条目，补充代码、模型卡、许可证或复现实验链接。

首版资料由 2026-11-11 建立，当前基线包含 26 篇论文和 33 个开源项目，后续按同一结构持续维护。
